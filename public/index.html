LaunchLocal — marketing platform

DashboardChat (Mistral)

Find local businesses that need marketing help

Uses Google Places when GOOGLE_PLACES_API_KEY is set; otherwise returns built-in demo leads so you can test the flow.

Automated website audit

Checks HTTPS, speed, titles, meta, mobile, robots.txt, sitemap, schema, alt-text and content depth, then re-scores the lead.

Instant website builder

Generates a fast, SEO-tagged one-page site with LocalBusiness schema, copy from Mistral (or solid templates), saved under /sites/.

SEO optimizer

Meta title/description, local keywords, weekly Google Business post ideas, and prioritized fixes. Runs an audit first if needed.

Auto email / SMS responder

Drafts personalized first-touch email + SMS using the audit findings. With SMTP/Twilio configured it sends; otherwise it returns previews. Inbound auto-replies can be added via webhooks later.
